# Kotoba Motion Sync — GitHub Pages版 v0.4

動画と音楽を別々に読み込み、音声波形に合わせて動画の分割・トリミング・配置を行うWebアプリの試作版です。

## iPadから公開する

1. GitHubの **New repository** で新しいリポジトリ `kotoba-motion-sync` を作ります。GitHub Free で Pages を利用するには **Public** にします。
2. リポジトリの **Add file → Upload files** で、このフォルダ内の **全ファイルを個別に** アップロードして **Commit changes** を押します。ZIPをそのままアップロードしないでください。
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch** を選びます。
4. Branch を **main**、Folder を **/(root)** にして **Save** します。
5. 数分後に Pages 設定画面に現れるサイトURLを Safari で開きます。
6. Safariの共有メニューで **ホーム画面に追加** を選ぶとアプリ風に起動できます。

## 編集と保存

- 編集画面の「動画を追加」「音声を追加」からiPad内の素材を選びます。
- 音声を聴きながらクリップを移動し、クリップ端のトリミングや再生位置での分割を行います。
- 「編集内容を保存」は **JSON形式の編集位置だけ** を保存します。動画や音声は含まれないため、元素材も必ず保管してください。再編集時は素材を再選択します。
- 自動保存・複数音声トラックは未実装です。随時手動で保存してください。
- 動画の書き出しは試験的であり、iPad Safariで動かない可能性があります。必ず短い素材で確認してください。

## 公開範囲・通信・オフライン

- **公開されるのはアプリのHTML/JS/CSSとアイコンのみ。** 動画・音声ファイルはアップロードせず、この端末のブラウザで開いて処理します。
- GitHub Pagesの **Webページ自体はインターネットに公開されます**。個人情報や作品データをリポジトリにアップロードしないでください。
- 一度オンラインで開くと、Service Workerがアプリ本体だけを保存するため、後でオフラインでも開ける場合があります。iPadがキャッシュを削除した場合には再度インターネット接続が必要です。
- 作品素材やJSON編集ファイルは自動キャッシュされません。タブを閉じたり更新すると未保存の編集内容や読み込み素材は失われます。
- 公開するWebアプリはパスワード保護されません。機密性が必要ならGitHub Pagesへの公開は避けてください。
